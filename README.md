# Universal AI Agent Rules

Koleksi aturan universal dan pedoman pengembangan untuk AI Coding Agents (Antigravity, Claude Code, Gemini CLI, Codex, Cursor, GitHub Copilot, Cline, Windsurf, dll.) serta pengembang manusia.

## Berkas Aturan
- **[`AGENTS.md`](AGENTS.md)** — Dokumen aturan universal & satu-satunya sumber kebenaran (Golden Rules, Keamanan Data, Git & Rollback, Anti AI Slop, No Native Browser UI, Mobile First).
- **[`CLAUDE.md`](CLAUDE.md)** — File penghubung untuk Claude Code (`@AGENTS.md`).
- **[`GEMINI.md`](GEMINI.md)** — File penghubung untuk Gemini CLI / Antigravity (`@AGENTS.md`).

## Panduan Penggunaan
Salin berkas `AGENTS.md` ke direktori root project Anda. Untuk tools yang membutuhkan berkas khusus, sertakan `CLAUDE.md` atau `GEMINI.md` sebagai file penghubung.
